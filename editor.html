Hymn Editor

Builds extra-hymns.json, the file that adds hymns to the catalog or corrects ones already in it. Nothing here touches the live site until you upload the file yourself.

Before you add a hymn, check who owns the words. The 1961 Trinity Hymnal texts are public domain, which is why they could be included. Hymns written since then usually are not. If a hymn is under copyright, you need permission or a licence such as CCLI before putting it on a public web page.

    Putting it live

    1. Download the file, or copy the text into extra-hymns.json.
    2. Put it in the repository beside index.html, replacing the old one.
    3. Commit. The app picks added hymns up on the next open with a connection, with no version bump needed.
